## How the run calls the model

- One adjudication call per audited case: deletion intent, ownership of softly linked records, and category refinement. Code merges the answer under fixed guardrails and applies the deletion policy.
- One vision call per screenshot in the evidence manifest, made once at start-up and shared by every case.
- A reply that is not valid JSON or fails schema validation is retried once with the error attached. Both attempts are billed and counted below.
- Validated answers are cached on disk under a hash of provider, model, prompt version, schema and input. Replaying an answer costs nothing, so the tables count the original billed call behind every answer the run used: they are the full cost of producing `output.csv`.
